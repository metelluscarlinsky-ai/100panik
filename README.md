# 100PANIK — Boutik E-commerce PWA

Sit e-commerce konplè pou mak rad **100PANIK**. Fonksyone tankou yon PWA (enstalable
sou iPhone, Android ak Desktop), ak yon panel admin sekrè pou jere tout bagay.

## Karakteristik

- Katalog pwodwi ak filtè (kategori, pri, rechèch)
- Panier ak kòmand an liy
- Sistèm livrezon pa depatman (Ayiti) + entènasyonal
- Swivi kòmand ak nimewo tracking
- Kòd pwomosyon
- Panel admin konplè (pwodwi, kòmand, kliyan, livrezon, pwomo, konfigirasyon)
- PWA enstalable sou iPhone (Safari), Android (Chrome), Desktop
- Dark mode + Light mode
- Responsive mobil-prensipal
- Sekirize ak JWT + bcrypt + rate limiting
